# Tripothon · 一起记得的地方

独立的多人回忆空间原型。现在包含项目首页与个人回忆笔记、可从头走完的世界示例、两个 World Labs 真实世界、新版实际操作录屏、视觉素材板，以及独立保留的本机多人后端。

## App 演示（2026-10-02 收尾）

- 入口：`public/demo.html`；静态包以 `docs/index.html` 为入口。首页 → 示例 / 我的地方 → 回忆 / 场景描述 / 我们的世界 / 版本记录；支持浏览器返回。
- 可以新建本机项目，输入文字、添加照片说明，恢复未发送的文字草稿，导出 JSON 备份。最多 5 个地方、每处 80 条回忆、共 6 张照片；照片在浏览器中缩放重编码，不上传。
- 个人项目的示例整理逐条引用原话，支持手动编辑和来源核对。新回忆会让旧描述进入待更新状态；确认形成独立快照，不覆盖旧版。新项目世界生成尚未开放。
- 桂花小院使用三位虚构人物、预设 Agent 记录和两个提前生成的真实世界。自由补充单独保存，永不被错误映射到已生成世界。没有在线 Agent 或远程多人同步。
- 草稿、照片和确认记录仅存在这个浏览器。清理浏览器数据会移除它们；导出备份用于留存，当前不提供自动跨设备同步或备份导入。
- 桌面默认约 12 MB 清晰 3D，手机默认约 6 MB 轻量 3D，可退出、重进、切换画质；真实全景用于加载失败回退。
- 新版 137 秒连续实际浏览器操作录屏（1280×900，H.264，约 6.5 MB）：`docs/walkthrough.mp4`。素材板：`docs/materials.html`；中英项目介绍与能力说明：`docs/submission.html`。
- 收尾没有新增 API 调用费用；公开演示沿用既有 GitHub Pages 地址；未操作比赛账号或报名。

不启动多人后端即可运行完整案例（Node ≥18，无需安装依赖）：

```sh
node scripts/serve-preview.mjs
```

打开 <http://127.0.0.1:4319/>。本机当前已有的静态服务为 <http://127.0.0.1:4318/demo.html>。公开体验：<https://maxi-max-dev.github.io/tripothon-memory-courtyard/>。线上只托管静态文件，个人输入仍仅存访问者浏览器。

## 启动

需要已有的 Node.js ≥ 22.15（本机 22.23.1）。没有 npm 依赖，不需要 `npm install`。

```sh
cd tripothon-memory-courtyard
npm start
```

- 完整演示入口：<http://127.0.0.1:4317/demo.html>
- 本机多人工作区：<http://127.0.0.1:4317/>
- World Labs 已生成桂花小院：<http://127.0.0.1:4317/generated-world.html>（合成文字，保存后浏览不再收费）
- 真实 SPZ 文件验证：<http://127.0.0.1:4317/spz-preview.html>（Niantic MIT 公开扫描，非用户世界）
- 视觉素材板：<http://127.0.0.1:4317/materials.html>
- 只监听本机回环地址；不能直接从其他手机、电脑或远程朋友访问。
- 使用 Chrome 普通窗口和无痕窗口，或两个不同浏览器，在同一个邀请链接进入。填写称呼形成独立 Cookie 身份；这不是正式账号登录。
- 新建项目勾选合成回忆即可体验。也可以取消勾选，从空白场景开始。
- 服务是普通前台进程。停止后运行 `npm start` 可恢复；没有安装开机启动、后台服务或持续访问配置。

## 目前真正运行的部分

1. 项目、邀请、1–5 位真实成员。合成回忆作者不计入成员数，不伪造在线人数。
2. 消息通过服务端 SQLite 写入，SSE 通知其他会话；客户端消息编号防止重试重复发送。
3. JPG/PNG/WebP 上传、说明和成员权限。浏览器先缩放至最长边 1600 并重新编码，去掉 EXIF。最大 8 MB、每个项目最多 12 张，HTTP 层限制请求体大小。
4. 原话引用示例、可点击来源、人工编辑、待确认问题、发起人确认。示例明确不具备 AI 识图、抽取或冲突判断能力。
5. 新消息和图片递增内容版本，过期描述不能确认或生成；确认快照不会被后续修改覆盖。
6. 确认后保存一份原创程序院子。成员共享同一份世界记录，可用 WASD/方向键、拖动和手机方向按钮探索。示例院子不随聊天自动改形，也不冒充 World Labs 结果。
7. 保存记录、失败状态、备用插画和 3D 重载；旧世界在补充文字后仍然保留。

## 数据与架构

- 服务：Node 原生 HTTP、SQLite（内置 `node:sqlite`）、SSE；原生 HTML/CSS/ES modules 与 WebGL。
- 使用已有工具实现，不依赖新增软件、外部字体或 CDN。SPZ 格式验证单独使用 Niantic MIT 公开扫描样例并附来源。
- 数据在 `data/tripothon.sqlite`，启用 WAL。表包括 users、sessions、projects、members、messages、photos、scenes、jobs、reference_images、paid_requests、job_polls。
- 图片以 BLOB 持久化；会话只存随机令牌的 SHA-256。生成请求的操作编号、状态与资产清单持久化。
- `lib/providers.mjs` 隔离模型/图片/世界供应商，支持注入 fetch 作无费用接口契约测试。
- 本地前端不保存密钥；`.env.example` 仅是配置说明，服务不会自动读取其他目录或项目的 `.env`。
- 世界任务按“确认描述 ID + 供应商”去重。外部 POST 结果不确定时不自动重提；有 operation ID 的任务只恢复查询，避免重复生成收费。
- 正式远程版本建议沿用网页与供应商接口，替换为托管身份系统、关系数据库、对象存储和持久任务队列。当前 SQLite/BLOB 适合本机 Demo，不宣称已具备生产多人服务。

## 真实供应商接入与准确阻碍

2026-10-01 已在用户授权的 1–2 个世界范围内，用现有 World Labs API 完成两次 `marble-1.1` 合成文字生成：共消耗 3,160 credits（约 USD 2.528）。两个世界的 3D、缩略图、全景与无凭据的生成清单均已归档，完整案例支持版本切换；浏览不会调用生成接口。本次没有启用群聊内持续付费调用，Agent 和参考图仍待联调。源码与静态发布包不含凭据、用户数据库或私人素材；素材板只包含本项目合成案例的浏览器截图。

真实服务默认关闭，即使单独配置 key 也不会开启。启用前需用户授权费用与资料发送，并在启动进程中提供配置；UI 每次真实操作另行确认发送。

| 能力 | 已实现适配器 | 仍需要 |
| --- | --- | --- |
| 记忆 Agent | OpenAI Responses、多图输入、严格 JSON Schema、来源 ID 校验、缺口/冲突/推测字段 | `OPENAI_API_KEY`、获准使用的 `OPENAI_MODEL`、API 额度和调用授权；真实质量评测尚未运行 |
| 图片生成 | OpenAI Image API，口述→参考图，生成图标记“推测” | key、`OPENAI_IMAGE_MODEL`、对应模型访问资格/可能的组织验证与费用授权；真实生成未测试 |
| World Labs | 参考图 prepare_upload→上传→generate→轮询→获取世界；文字/单图/多图；私有 permission | `WORLDLABS_API_KEY`、独立 API 额度和授权。Marble 网页订阅额度不能直接用于 API |
| 真实世界 3D 展示 | 原生 WebGL 高斯查看器、SPZ v1–v4 解码、本机资产归档、成员权限、备用内容 | 已验证 World Labs 真实输出、资产下载与桌面轻量展示；手机实机性能仍待验收 |

完整模型、费用、次数限制和用户本机隐藏输入步骤见 [INTEGRATION.md](INTEGRATION.md)。共同开关默认关闭，三项次数默认均为 0。不要在命令行、聊天、前端或版本库粘贴真实 key。

本次真实验证仅涵盖文字 → World Labs 世界 → 本机归档 → 轻量 3D 展示；没有上传私人照片，没有运行 Agent 整理或独立参考图生成。群聊到供应商的完整在线链路仍只有 mock 契约测试，不能据此声称已全部联通。

原始图片应先按地点、目标年代、视角整理；不要把冲突年代直接拼在一起。隐藏几何会被想象。公开 API 目前核对到的是生成、获取、导出等能力，本 Demo 不承诺支持网页版局部全景编辑；文字修改会更新描述，重新确认后可创建新的世界记录，旧版本保留；本机后端的付费开关仍默认关闭；本次另行完成了授权范围内的两个归档世界。第二版实际产生了桌子形状等附带变化，页面明确标注重新生成的限制。

## 群聊助手与版本

- 群聊助手默认关闭，只有发起人能启用或暂停。模拟模式显著标为“非 AI”，只用固定规则演示，不识图。
- 消息或照片更新后静默 1.8 秒合并一次整理；共享项目锁阻止并发，同资料版本不重复调用。助手消息不纳入来源，避免自触发循环。
- 追问按规范化文字去重；不声称语义级去重。每项目最多 10 次模拟整理，重启不清零。
- 真实模式要求模型、凭据、总开关、明确发送同意与持久化调用额度；单次完成后自动关闭。没有配置时明确阻塞，不回退为示例。
- 资料 r、描述 D、确认快照、世界 W 分别展示。新回忆或手动编辑不会更新旧世界；可查看旧世界的确认描述。
- 世界生成始终由发起人另行确认，群聊助手不生成图片或世界。
